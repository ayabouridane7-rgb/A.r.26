} }// توليد 50 مستوى بشكل مبرمج وتدرج احترافي بالصعوبة const generateLevels = () => { const levels = []; // مصفوفة ألوان نيون للخلفيات التناغمية للمستويات const colors = [ '#0a0a12', '#0f0c1b', '#0b161e', '#1a0b16', '#0d1a10', '#1c190b', '#1f0f0f', '#0f1f1a', '#140f1f', '#0f1c1f' ]; for (let i = 1; i <= 50; i++) { // حساب السرعة (الفاصل الزمني بالملي ثانية - كلما قل كان أسرع) // يبدأ من 900ms وينزل تدريجياً حتى 320ms في مستويات الجنون الأخيرة const speed = Math.max(900 - (i * 12), 320); // عدد النقاط/الخطوات المطلوبة لتخطي هذا المستوى const steps = 10 + (i * 2); levels.push({ level: i, speed: speed, targetSteps: steps, bgColor: colors[i % colors.length], // نمط النغمة الموسيقية للمستوى ليتغير اللحن بتغير المستويات noteType: i % 3 === 0 ? 'triangle' : (i % 2 === 0 ? 'sawtooth' : 'sine') }); } return levels; }; const GAME_LEVELS = generateLevels();class EffectsManager { constructor() { this.audioCtx = null; } initAudio() { if (!this.audioCtx) { this.audioCtx = new (window.AudioContext || window.webkitAudioContext)(); } } // توليد نغمة الـ Synth الأساسية للإيقاع والموسيقى التناغمية الخلفية playBeatTone(frequency = 220, type = 'sine', duration = 0.15) { if (!this.audioCtx) return; const osc = this.audioCtx.createOscillator(); const gainNode = this.audioCtx.createGain(); osc.type = type; osc.frequency.setValueAtTime(frequency, this.audioCtx.currentTime); gainNode.gain.setValueAtTime(0.15, this.audioCtx.currentTime); gainNode.gain.exponentialRampToValueAtTime(0.001, this.audioCtx.currentTime + duration); osc.connect(gainNode); gainNode.connect(this.audioCtx.destination); osc.start(); osc.stop(this.audioCtx.currentTime + duration); } // صوت عند الضغط الناجح (Hit) playHitSound() { this.playBeatTone(440, 'triangle', 0.1); } // صوت عند الخطأ (Miss) playMissSound() { this.playBeatTone(130, 'sawtooth', 0.3); } // تأثير نص الـ Combo العائم createComboPopup(cellElement, text) { const rect = cellElement.getBoundingClientRect(); const popup = document.createElement('div'); popup.className = 'combo-popup'; popup.innerText = text; popup.style.left = `${rect.left + rect.width / 2 - 20}px`; popup.style.top = `${rect.top}px`; document.body.appendChild(popup); setTimeout(() => popup.remove(), 600); } // وميض نيون سريع للمربع عند الضغط عليه triggerFlash(element, colorClass) { element.style.transform = 'scale(0.95)'; setTimeout(() => element.style.transform = 'scale(1)', 100); } } const effects = new EffectsManager();class RhythmGame { constructor() { this.currentLevelIdx = 0; this.score = 0; this.combo = 0; this.hits = 0; this.misses = 0; this.totalAttempts = 0; this.isPlaying = false; this.isPaused = false; this.ballPosition = 4; // تبدأ الكرة من المربع الأوسط (الفهرس 4) this.targetPosition = null; this.gameInterval = null; this.hasHitCurrentTarget = false; this.initElements(); this.initEvents(); this.loadProgress(); } initElements() { this.cells = document.querySelectorAll('.grid-cell'); this.ball = document.getElementById('ball'); this.scoreEl = document.getElementById('score'); this.comboEl = document.getElementById('combo'); this.accuracyEl = document.getElementById('accuracy'); this.levelNumEl = document.getElementById('level-num'); this.startScreen = document.getElementById('start-screen'); this.gameScreen = document.getElementById('game-screen'); this.gameOverScreen = document.getElementById('game-over-screen'); this.pauseModal = document.getElementById('pause-modal'); this.maxLevelEl = document.getElementById('max-level'); } initEvents() { document.getElementById('start-btn').addEventListener('click', () => this.startGame()); document.getElementById('restart-btn').addEventListener('click', () => this.startGame()); document.getElementById('pause-btn').addEventListener('click', () => this.togglePause()); document.getElementById('resume-btn').addEventListener('click', () => this.togglePause()); // دعم متجاوب بالكامل: اللمس للهواتف والفأرة للكمبيوتر this.cells.forEach(cell => { const handleInput = (e) => { e.preventDefault(); if (!this.isPlaying || this.isPaused) return; const clickedIdx = parseInt(cell.getAttribute('data-index')); this.checkHit(clickedIdx, cell); }; cell.addEventListener('mousedown', handleInput); cell.addEventListener('touchstart', handleInput, { passive: false }); }); } startGame() { effects.initAudio(); this.score = 0; this.combo = 0; this.hits = 0; this.misses = 0; this.totalAttempts = 0; this.currentLevelIdx = 0; this.isPlaying = true; this.isPaused = false; this.switchScreen(this.gameScreen); this.updateHUD(); this.startLevelLoop(); } startLevelLoop() { if (this.gameInterval) clearInterval(this.gameInterval); const currentLevel = GAME_LEVELS[this.currentLevelIdx]; document.body.style.backgroundColor = currentLevel.bgColor; this.levelNumEl.innerText = currentLevel.level; // تشغيل حلقة التوقيت الخاصة بالمستوى الحالي this.gameInterval = setInterval(() => { if (this.isPaused) return; // التحقق إذا كان اللاعب قد فاتتة الخطوة السابقة ولم يضغط if (this.targetPosition !== null && !this.hasHitCurrentTarget) { this.registerMiss(); } this.moveBallRandomly(); }, currentLevel.speed); } moveBallRandomly() { this.hasHitCurrentTarget = false; // إزالة الإضاءة السابقة للمربعات this.cells.forEach(c => c.classList.remove('active-target')); // تحديد موضع المربع العشوائي التالي للكرة (مختلف عن الحالي) let nextPos; do { nextPos = Math.floor(Math.random() * 9); } while (nextPos === this.ballPosition); this.targetPosition = nextPos; this.ballPosition = nextPos; // تحريك الكرة بسلاسة عبر الـ CSS Transition المدمج const targetCell = this.cells[this.targetPosition]; this.ball.style.left = `${targetCell.offsetLeft + 10}px`; this.ball.style.top = `${targetCell.offsetTop + 10}px`; // إضاءة المربع المستهدف بالنيون targetCell.classList.add('active-target'); // عزف لحن الإيقاع الخلفي التلقائي (موسيقى المستوى) const levelConfig = GAME_LEVELS[this.currentLevelIdx]; effects.playBeatTone(200 + (this.ballPosition * 30), levelConfig.noteType, 0.1); } checkHit(clickedIdx, cellElement) { this.totalAttempts++; if (clickedIdx === this.targetPosition && !this.hasHitCurrentTarget) { // Hit ناجح! this.hasHitCurrentTarget = true; this.hits++; this.combo++; if (this.hits >= currentLevel.targetSteps) { this.nextLevel(); } } else { // ضغطة خاطئة في مكان خاطئ this.registerMiss(); effects.triggerFlash(cellElement); } this.updateHUD(); } registerMiss() { this.combo = 0; this.misses++; effects.playMissSound(); // نهاية اللعبة عند ارتكاب أكثر من 10 أخطاء في المستوى الحالي if (this.misses > 10) { this.endGame(); } this.updateHUD(); } nextLevel() { if (this.currentLevelIdx < GAME_LEVELS.length - 1) { this.currentLevelIdx++; this.hits = 0; // إعادة ضبط عداد خطوات المستوى الجديد this.saveProgress(); this.startLevelLoop(); } else { alert("مبارك! لقد ختمت جميع مستويات النيون بنجاح!"); this.endGame(); } } updateHUD() { this.scoreEl.innerText = this.score; this.comboEl.innerText = this.combo; // حساب نسبة الدقة الاحترافية const acc = this.totalAttempts > 0 ? Math.round((this.hits / this.totalAttempts) * 100) : 100; this.accuracyEl.innerText = `${acc}%`; } togglePause() { this.isPaused = !this.isPaused; this.pauseModal.style.display = this.isPaused ? 'flex' : 'none'; } endGame() { this.isPlaying = false; clearInterval(this.gameInterval); document.getElementById('final-level').innerText = this.currentLevelIdx + 1; document.getElementById('final-score').innerText = this.score; document.getElementById('final-misses').innerText = this.misses; this.switchScreen(this.gameOverScreen); } switchScreen(screen) { document.querySelectorAll('.screen').forEach(s => s.classList.remove('active')); screen.classList.add('active'); } // إدارة الحفظ التلقائي عبر الـ Local Storage saveProgress() { const savedMax = localStorage.getItem('neonRhythmMaxLevel') || 1; const reachedLevel = this.currentLevelIdx + 1; if (reachedLevel > savedMax) { localStorage.setItem('neonRhythmMaxLevel', reachedLevel); } this.loadProgress(); } loadProgress() { const maxLevel = localStorage.getItem('neonRhythmMaxLevel') || 1; this.maxLevelEl.innerText = maxLevel; } } // تشغيل اللعبة عند تحميل المستند بالكامل document.addEventListener('DOMContentLoaded', () => { new RhythmGame(); });
